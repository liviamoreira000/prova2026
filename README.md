# MoveCheck 📱

## Sobre o projeto
O MoveCheck é um aplicativo simples feito em React Native com Expo.
O aplicativo usa o **acelerômetro do celular** para detectar se o aparelho está parado ou em movimento.

## Funcionalidades
* Ligar e desligar o sensor.
* Detectar movimentos do celular.
* Mostrar os valores dos eixos X, Y e Z.
* Informar se o celular está parado ou em movimento.

## Tecnologias usadas
* React Native
* Expo
* JavaScript
* Expo Sensors
* Acelerômetro do celular

## Como executar
1. Abrir o projeto no **Expo Snack**.
2. Adicionar a dependência `expo-sensors`.
3. Abrir o aplicativo pelo **Expo Go** no celular.
4. Clicar em **Iniciar sensor**.
5. Mexer o celular para testar o funcionamento.

## Objetivo
O objetivo do projeto é demonstrar o uso de um **sensor do celular**, utilizando o acelerômetro para identificar movimentos.
